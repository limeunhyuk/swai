# 컴공으로 살아남기 · 중간 발표 프로토타입

HTML·CSS·JavaScript와 사전 작성 콘텐츠로 구성한다. DB·AI 추천 엔진·자동 크롤러는 추가하지 않는다. 기존 [공개 사이트](https://savecs.netlify.app/)와 GitHub–Netlify 배포를 유지한다.

## 실행

`start.cmd` 또는 `npm run dev` → http://127.0.0.1:4173/ . Node.js가 필요하다. 종료는 Ctrl+C.

## 현재 범위 — 콘텐츠 2026-11-02.5

- 홈: 이력서 즉시 확인 / 3학년 시작하기. 버튼마다 짧은 설명.
- 즉시 확인: 입력 없이 네 학기 로딩(기본 약 1.6초, 동작 줄이기 설정 시 단축) 후 김컴공 예시 이력서·진로·실제 공고. 세 예시만 순환하며 실제 게임 완료로 기록하지 않는다.
- 실제 게임: 성·이름만 선택 입력. 빈 칸만 김/컴공으로 보충. 3-1~4-2의 진로 1개+일상 1개씩 총 8선택.
- 진로: 3-1 프로젝트/자격증/인턴 준비 → 3-2 해당 준비의 사건 → 4-1 유지 또는 변경 → 4-2 마무리. 최종 추천은 4-1의 마지막 방향, 이전 경험은 보존한다. 자격증은 정보처리기사/SQLD/빅데이터분석기사 준비를 고르며 취득으로 기록하지 않는다.
- 스탯: 공부 네 항목은 각 가로 5칸×세로 2줄, 생활 세 항목은 세로 배치. 효과 순합 +2·개별 ±2 이내, 0~10 경계에서 실제 변화량 표시.
- 학점: 3.50/4.3 시작, 두 선택 후 룰렛 자동 실행. 다음 학기 버튼은 유지. 중간 하락을 허용하는 전반적 상승 시연값이며 결과에는 2학년~4-2 선 그래프.
- 결과: 실제 선택 경험·구체 직무와 취업 분야·공고·피드백을 구분하고 다시 하기 강조. 즉시 보기 하단은 이름 설정부터 실제 게임으로 이동.
- 추천: 프로젝트→서비스 통합 엔지니어/대기업 SI·IT 서비스, 자격증→정보시스템 운영 엔지니어/공기업·공공기관 전산직, 인턴→AI 에이전트 엔지니어/IT 서비스·플랫폼 기업. 실제 자격·합격 예측이 아닌 진로 예시다.
- 모집: 각 경로 두 개씩 총 여섯 실제 공고. 카드 전체를 누르면 원문 새 탭으로 직행. [출처](JOBS.md).
- 의견·이메일 모두 선택. 하나 이상 입력하면 제출 가능, 실제 저장 응답 뒤에만 입력 초기화.

## 기록·분석

브라우저 → Netlify 함수 → 기존 Apps Script GET/JSONP insert → 기존 tab_master/tab_final. Google 로그인·새 탭·새 비밀키가 필요하지 않다. `.env`는 Git 제외하고 배포 환경변수 APPS_SCRIPT_URL을 유지한다. [저장 설정](SETUP.md).

방문·게임 시작/첫 선택/완주·즉시 보기 시작/예시 도달·원문 클릭과 피드백을 기록한다. `mode=game/instant`를 기존 landingUrl 또는 advice JSON에 넣는다. 실제 지원 완료는 추적하지 않는다. 자동 재전송은 하지 않고 분석에서 ID 중복 제거한다.

`node scripts/summarize-legacy.mjs tab_master.csv tab_final.csv`로 두 탭 CSV를 분석한다. 출처·플랫폼·게시판·게시일별로 묶으며 각 수준의 고유 브라우저를 다시 중복 제거한다. 예시 도달·예시 공고 클릭은 게임 시작 없이도 집계하고 게임 완주와 구분한다. 테스트는 제외하며 시트 전체 행 수를 방문 수로 세지 않는다. 시트 내 자동 집계 탭은 추가하지 않았다.

## 홍보 링크

`/r/e01`처럼 짧은 주소에서 같은 홈을 제공하고 public/campaigns.js의 대응표로 내부 출처를 정한다. 내부 출처는 플랫폼__게시판__YYYYMMDD__HHmm__회차. 기존 utm/utm_source도 계속 지원한다. 짧은 경로가 쿼리보다 우선하며 미등록 코드는 unregistered로 분류한다. 전달된 링크는 원래 배포 코드로 집계된다.

[PROMOTION.md](PROMOTION.md)의 예약 코드는 실제 게시 일정이 아니다. 실제 게시 전에 한국 시간의 날짜·시각·게시판 별칭을 다음 명령으로 정하고 commit/push한다. 확정한 코드는 재사용하지 않는다.

`node scripts/add-campaign.mjs e04 everytime yonsei-free YYYYMMDD HHmm 1`
