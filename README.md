# 컴공으로 살아남기 · 1차 체험판

프레임워크와 추가 설치 없이 HTML·CSS·JavaScript로 플레이하는 중간 프리토타입이다. Node.js가 필요하다. 현재 사용자 PC에 설치된 Node.js로 실행할 수 있다.

## 실행

1. 이 폴더의 `start.cmd`를 더블 클릭한다. 또는 이 폴더에서 터미널을 열어 `node scripts/serve.mjs`를 실행한다. npm을 사용할 수 있으면 `npm run dev`도 같다.
2. `Local: http://127.0.0.1:4173`이 표시되면 브라우저에서 해당 주소를 연다.
3. 종료하려면 서버 창에서 `Ctrl+C`를 누르거나 창을 닫는다.

`public/index.html`을 파일로 직접 여는 대신 로컬 HTTP 서버를 사용한다. JS 모듈과 JSON 콘텐츠를 HTTP로 읽는 구성이다. 서버는 이 컴퓨터의 `127.0.0.1`에서만 제공한다.

## 구현 범위

- 캐릭터 성별·MBTI 필수 설정. 설정은 프로필 표시용이다.
- 8학기·생활/진로 교대·각 3선택지. 일곱 스탯의 시작값과 효과는 기획 07을 따른다.
- 선택 전 변화 방향, 선택 후 상·하한 적용 뒤 실제 증감·한 줄 피드백.
- 선택을 한 번 확정한 뒤 수동으로 다음 학기 진행. 모든 조합에서 졸업한다.
- 최종 스탯·접힌 실제 8선택 기록·공통 프론트엔드 진로 예시·공식 공고 2개.
- 선택적 건의사항 입력·1,000자 제한. **저장 서버 미연결**을 표시하며 전송 시도에도 내용을 지우거나 성공으로 표시하지 않는다.

한 판은 페이지 메모리에서만 유지한다. 새로고침하면 처음부터 시작한다. 이번 버전에서는 브라우저 식별·행동 기록 전송도 아직 구현하지 않았다. 플레이·건의사항은 어디에도 저장되지 않는다.

## 파일과 수정

| 파일 | 역할 |
| --- | --- |
| `public/content.json` | 8장면·24선택·효과·피드백·프로필·공통 결과·공고를 관리하는 유일한 콘텐츠 파일 |
| `public/game.js` | 설정 검사·선택 확정·스탯 계산·학기 진행 |
| `public/app.js` | 화면 표시·입력·접근성·진행 조작 |
| `public/styles.css` | 모바일 우선 배치와 PC 스타일 |
| `scripts/check-game.mjs` | 콘텐츠 구조·기준 경로·전수 조합 검사 |
| `scripts/serve.mjs` | 별도 라이브러리 없는 로컬 정적 서버 |
| `netlify.toml` | 향후 제품 저장소 루트 기준 공개 폴더 `public` 설정 |

문구·효과·공고를 바꾸려면 `content.json`을 편집하고 검증 후 브라우저를 새로고침한다. 새 콘텐츠를 실험에 사용할 때는 `version`도 갱신한다. 기록과 기획 원본은 상위 `project/md/06-아이디어구체화.md`와 `07-중간구현기획.md`에 유지한다.

## 검증

```powershell
node scripts/check-game.mjs
```

`npm test`로도 실행할 수 있다. 8학기·24선택과 **6,561조합 전부**의 결과 도달, 스탯 범위, 실제 증감, 이력, 중복 반영 방지, 선택 전 진행 방지를 확인한다. 별도 기준 경로 세 개를 성별·MBTI의 32개 설정으로 실행한다. 전체 프로필마다 모든 조합을 다시 수행하는 검사는 아니다.

2026-10-27 확인:

- 위 게임 검사 통과, 로컬 HTTP 200 응답.
- 브라우저에서 미선택·한 항목 선택 시 시작 불가, 두 항목 선택 시 시작 가능.
- 모바일에서 A 전부·C 전부 경로 각각 완주, 일곱 스탯과 실제 8선택 기록 확인.
- 의견 전송 시 미저장 안내·입력 유지·1,000자 제한, 브라우저 오류/경고 로그 없음.
- 시작·플레이·결과 각각 320·390·768·1440px 가로 넘침 없음. 실제 휴대폰 기기 검사는 아니다. 하한에서 추가 감소 시 실제 0 변화 안내도 브라우저에서 확인했다. 스크린샷은 기획 07에서 연결한다.
- 두 기업 공식 채용 상세에서 신입/경력무관·모집 표시 확인. 공개 직전 다시 확인해야 한다.

자동 게임 검사와 브라우저 조작 확인이며 사용자 수요·재미·불안 감소·평균 플레이 시간의 실험 결과가 아니다. QA 이미지에는 테스트용 캐릭터만 포함된다.
